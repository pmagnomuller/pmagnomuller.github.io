An original, self-written study guide covering all 23 patterns from *Design Patterns* (Gamma, Helm, Johnson, Vlissides, 1994). Every pattern gets the same eight fields — intent, problem, solution, structure diagram, TypeScript code, applicability, trade-offs, and where you have already used it — so patterns can be compared side by side.

**What's inside**

- **Part I — Foundations:** what a pattern is, encapsulate-what-varies, composition vs inheritance, SOLID, a four-week study plan, diagram notation.
- **Part II–IV — The 23 patterns:** 5 creational, 7 structural, 11 behavioral. Each with a UML class diagram; most also with a runtime view (sequence, object, or state diagram of the code example executing).
- **Part V — Applying patterns:** symptom → pattern decision table, look-alike disambiguation (Strategy vs State, Proxy vs Decorator vs Adapter vs Facade…), a relationship map, over-engineering signals, modern language replacements, and a 60-question self-test with answer key.

All prose, diagrams, and code are newly written; only the pattern names and catalogue structure follow the GoF book.
